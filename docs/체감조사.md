# 펀치미터 체감 조사 안내 (PLAN 작업 23)

- 목표 (PRD 성공 기준): 테스트 사용자 **10명 중 8명 이상**이 "얼마나 아플지 감이 온다"고 답한다.
- 이 조사는 실제 사람에게 물어야 해서 앱 개발 중에 대신 할 수 없다. 아래 순서대로 진행하고 결과를 "기록표"에 적는다.
- 개인정보는 받지 않는다. 이름 대신 번호(1~10)만 적는다.

## 1. 참가자 고르기 (10명)

| 묶음 | 인원 | 예 |
|---|---|---|
| 격투기·복싱 경험 있음 | 4명 | 체육관 회원, 선수 |
| 운동은 하지만 격투기는 안 함 | 3명 | 헬스·구기 운동 |
| 운동 경험 거의 없음 | 3명 | 일반인 |

## 2. 진행 순서 (1명당 약 10분)

1. 앱을 연다 (`npm run dev` 후 http://localhost:3000, 또는 배포 주소).
2. 진행자가 한 문장으로 설명한다: "선수 정보와 기술을 고르면 3D로 재생하고, 힘과 의학적 판단을 연구 근거와 함께 보여 주는 실험실이에요."
3. 참가자가 직접 해 본다 (진행자는 돕지 않고 지켜본다).
   - ① 자기와 비슷한 체격으로 선수 A를, 상대를 선수 B로 넣는다.
   - ② 크로스로 턱을 쳐서 재생하고 결과를 읽는다.
   - ③ 같은 크로스를 "팔로 막음"으로 바꿔 재생하고 결과를 비교한다.
   - ④ 훅 → 크로스 → 로우킥 연타를 만들어 재생하고, 누적 충격 색을 본다.
   - ⑤ 관절기에서 암바를 골라 각도를 올려 본다.
4. 아래 질문지를 묻는다.

| Q2 | 숫자(충격력·강도 지수)가 이해되었나요? | 1 전혀 ~ 5 매우 |
