# 연구 재현 검증 (PLAN 작업 22)

- 날짜: 2026-11-24
- 성공 기준 (PRD): 공개 연구 사례 **5개 이상**에서 앱 결과가 연구 측정값의 **±15% 안**.
- **결과: 10개 중 3개만 ±15% 안 → 성공 기준 미달.**
- 방법: 연구 참가자의 평균 체중·키와 측정 속도를 앱에 그대로 넣고, 앱이 계산한 추정 충격력(계체량 기준)을 연구의 측정 힘과 비교했다.
  - 코드: `lib/lab/validation.ts`, 실행: `npx vitest run lib/lab/validation.test.ts --silent=false`
  - 앱 계산식은 이 결과에 맞춰 고치지 않았다 (맞추면 검증이 아니라 끼워 맞추기가 된다).
- 연구에 적혀 있지 않아 넣은 가정: 펀치 글러브 10oz(무게 0.28 kg만 더해짐), 성별 미기재 → 남성.

## 왜 어긋나는가 (추정)

1. **측정한 힘의 종류가 다르다.** 앞차기(Vágner)는 최대 힘이 아니라 평균 충격 힘, 하이킥(Gavagan)은 패드가 흡수한 뒤의 힘, Dinu 2020은 직접 잰 힘이 아니라 관성 센서로 추정한 힘이다.
2. **숙련도가 반영되지 않는다.** 앱은 체중(분절 무게)과 속도만 쓰므로, 체중이 비슷한 엘리트와 주니어의 차이(같은 속도에서 힘이 2~5배)를 설명하지 못한다. 주니어 훅 +248%가 대표적이다.
3. **접촉 시간이 하나다.** 모든 기술에 스트레이트 펀치(Walilko 2005)의 접촉 시간(약 7.7 ms)을 쓴다. 킥·패드 충돌은 접촉 시간이 더 길어 실제 최대 힘이 낮을 수 있다.
4. **"최고 속도"와 "닿는 순간 속도"가 섞여 있다.** Liu 2022a는 최고 속도라 앱이 힘을 크게 계산한다(+21~55%). 닿는 순간 속도를 쓴 Liu 2022b는 −15.9%로 가깝다.

## 다음에 할 수 있는 것 (결정 필요)

- **기술별 접촉 시간 보정:** 킥·패드 연구로 기술마다 접촉 시간을 정하면 오차가 줄 수 있다. 다만 같은 연구로 맞추고 같은 연구로 검증하면 순환 논리가 되므로, 맞추는 연구와 검증하는 연구를 나눠야 한다.
- **숙련도 입력:** "초보 / 숙련 / 엘리트"를 받아 유효 질량을 바꾸는 방법. 근거 연구가 더 필요하다.
- **비교 대상 정리:** 평균 힘·패드 힘·센서 추정 힘은 "최대 충격력"과 직접 비교할 수 없으므로, 비교 사례에서 빼고 직접 잰 최대 힘 사례를 더 찾는다.
